# PhotoCraft 风格工作台

本轮按用户确认的范围复刻编辑器界面与常用操作，保留 Image Studio 的浏览器引擎、AI 编辑、项目服务和独立/平台双模式。

参考 [PhotoCraft](https://github.com/storytold/photocraft) 的源码基线为
`7b3d131bc821e467d81e6614c8a70b62fa52bf16`。主要参考入口：

- `crates/ui-egui/src/theme.rs`：工作台分区和语义颜色。
- `crates/ui-egui/src/palette.rs`：通过命令搜索选择工具、操作和面板。
- `crates/ui-egui/src/panels.rs`：图层、历史与工具面板布局。

实现采用现有 React + Konva 和 TypeScript 文档命令，未嵌入 Rust/WASM 引擎，未复制上游代码、品牌或图片。

## 界面与操作

| 能力 | 行为 |
| --- | --- |
| 浅色工作台 | 按用户最新要求只使用浅色，不提供深色切换，也不读取旧深色偏好。布局参考 PhotoCraft，保留 Image Studio 自身的浅色视觉。 |
| 顶部工具选项 | 跟随当前工具显示颜色、画笔大小/不透明度/流量、选区组合模式、魔棒容差、形状类型。详细设置仍在属性面板。 |
| 文档栏 | 显示项目名、画布尺寸和 RGB 工作流，提供命令面板入口。只有一个活动文档，不伪装成多文档标签系统。 |
| 常用菜单 | 文件、编辑、图层、选区、调整、滤镜、视图和设置。新增菜单从统一命令目录读取可用性和执行回调。 |
| 命令搜索 | `Ctrl+K` / `⌘K`，或文档栏“命令”。支持本地化名称、英文关键词、命令 ID 和模糊匹配；↑↓ 选择、Enter 执行、Esc 关闭。不可用命令仍显示但不能执行。 |
| 面板布局 | 右侧属性/历史在上方切换，图层面板常驻下方，选中图层即可同时查看属性和图层栈。位置与旋转数值可编辑，宽高显示当前变换后的尺寸。 |
| 历史面板 | 在右侧上方与属性切换；显示保留的操作、当前状态与可重做操作，提供撤销和重做。历史仍是当前会话的预算内记录，不是持久快照。 |
| 快捷图层变换 | 图层菜单提供顺/逆时针 90° 旋转和水平/垂直翻转。保持图层中心，保留源像素，同步关联蒙版，支持撤销/重做和保存/重开。 |
| 常用编辑 | 图层菜单提供新绘图层、复制、删除、添加蒙版和安全向下合并；调整菜单沿用现有参数编辑；滤镜菜单沿用现有本地编辑器、透视和 AI。 |

## 快捷键与边界

- 画布聚焦时，`Ctrl+J` / `⌘J` 复制图层，`Ctrl+A` / `⌘A` 全选，`Ctrl+D` / `⌘D` 取消选区，`Ctrl+Shift+I` / `⌘Shift+I` 反选。全选支持总像素数不超过 16,777,216 的可编辑栅格/绘图/文字形状图层，避免无界分配选区和预览内存。
- 自定义快捷键优先于新增图层/选区快捷键。输入框、可编辑文字、组合输入和弹窗保留自己的键盘事件。
- 命令面板打开后暂停画布快捷键；关闭后恢复先前焦点。其他编辑弹窗打开时，不能再用快捷键打开命令面板。
- 锁定图层和锁定的祖先禁止变换；调整层和蒙版层没有独立快捷变换。活动像素选区禁止整体变换其来源图层。
- 向下合并沿用 `planLayerMerge` 的安全条件。AI 沿用已保存项目、可编辑栅格图层及现有运行模式约束。
- 工作台继续使用现有数据库、鉴权和 AI 契约；编辑数据版本和渲染扩展见下文。

## 第二轮：常用编辑流程（2026-10-07）

- 图层缩略图按可见区域延迟渲染，显示关联蒙版与所属图层。
- 单图层相对画布对齐；同一父级多图层按变换后的边界对齐、按间隙等距分布。锁定、隐藏或跨父级选择不执行。拖动结束时可吸附根图层到画布边缘或中心，阈值为屏幕 6 px；不吸附数值输入或旋转缩放。
- 文档栏进入主画布裁剪，拖动矩形或输入 X/Y/W/H 后应用。仅改变画布与根节点位置，保留原始像素、图层内容及关联蒙版；整个操作可撤销。
- 属性面板增加可编辑投影与外描边，仅支持 raster/paint/annotation。描边宽度 0–16 px、投影模糊 0–64 px、偏移 ±256 px。效果根据蒙版后的透明度渲染；画布、缩略图、PNG/JPEG/WebP 和 OpenRaster fallback 共用渲染器。
- 历史行支持跳转，包含异步像素历史。恢复期间工作台暂停输入，像素源按每一步重新加载；中途失败恢复历史栈并丢弃临时画布。历史仍受原有条数和内存预算限制，不跨重开持久化。
- 导出增加宽高比锁定与编码结果预览，显示实际编码大小。参数变更延迟 400 ms，取消过期任务并释放 URL；超过预览内存警戒线时只保留手动导出。

## 第三轮：功能补齐（2026-10-07）

- **面板**：右侧宽度 240–480 px、上下分区 25%–70% 可拖动或键盘调整，保存在本地浏览器；窄屏隐藏宽度拖动柄，保持浅色。
- **文字**：双击画布文字直接编辑，失焦或 Ctrl/⌘+Enter 应用，Esc 取消；支持字重、斜体、字距、行距及按字符自动换行。沿用本机字体，不包含字体打包、字体授权或复杂专业排版。
- **选区**：支持扩展、收缩和平滑（方形邻域、半径 1–128 px），选区存档随项目持久化，最多 32 个，恢复到同尺寸图层。选区仍为二值；软边沿用图层蒙版羽化，不宣称发丝级边缘识别。
- **布局**：网格、标尺与可拖动参考线，参考线可键盘移动、Delete/双击删除，最多 100 条且随项目保存。拖动根图层结束时可吸附画布、可见同级图层、参考线与网格；嵌套图层不执行自动吸附。
- **滤镜链**：栅格、绘图与文字形状图层可保留最多 8 个参数化滤镜，支持模糊、锐化与既有颜色/空间调整；支持排序、开关、不透明度及添加时将当前选区固化为滤镜蒙版。源内容保留，预览、缩略图与导出共用顺序渲染。滤镜蒙版目前为二值；无链接外部智能对象。
- **路径**：文档栏钢笔入口可点击添加锚点、拖动生成贝塞尔控制柄；可移动锚点/控制柄、删除锚点、转为角点、切换闭合与设置填充/描边。属性入口或双击重新编辑，最多 1000 个锚点；不包含路径布尔运算。
- **矢量蒙版**：栅格、绘图与文字形状图层可以在画布上绘制闭合路径作为蒙版，重新编辑、反转与移除；路径使用所属图层局部坐标，跟随图层/组变换。与栅格蒙版相交，滤镜先执行、蒙版后裁切、图层效果最后渲染。矢量蒙版同时约束局部栅格编辑；带滤镜/效果/矢量蒙版的原图保留调整层编辑路径，避免重复烘焙。不支持组矢量蒙版。

文档升级至 **v14**：新增可选文字样式、`guides`、`selectionArchives`、`filters`、`path` 元素和内嵌 `vectorMask`；v1–v13 自动迁移，旧字段保持。应用与平台 BFF 的文档契约和元素目录保持逐字一致，发布时必须先升级或同步升级 BFF。OpenRaster 原生扩展保留可编辑数据，普通读取器获得烘焙后的图层像素。

用户明确要求 **PSD 暂不实现**，本轮没有加入 PSD/PSB 代码或依赖；Firefox 等浏览器的笔触测试不执行。普通 Chromium 编辑流程验收不包含画笔输入/压力测试。

## AI 专用编辑区

AI 编辑固定为去噪、去模糊、超分辨率、抠图、老照片修复、上色和局部修补。
不再按图片输入/输出宽泛收集平台全部工具；其他模型不显示，平台与独立模式浏览器
适配器均拒绝对未纳入范围的模式发起新提交。平台其他应用的模型能力不受影响。

- 去噪自动处理，不虚构强度；去模糊采用 manifest 强度。两者默认 100% 检查细节。
- 超分辨率按模型倍率与长边上限计算预计尺寸；真实结果显示实际尺寸。
- 抠图可切换透明、浅色、深色背景检查边缘，仅改变预览，不把背景写入输出。
- 老照片修复采用独立 `old_photo_restore` 模式，提供强度与倍率；未启用时禁止新运行。
- 上色采用模型与推理尺寸选择，结果可与原图对比。
- 局部修补直接标记/擦除区域、调整标记尺寸、清空或恢复当前选区与关联蒙版；
  标记使用源图像坐标，100% 预览支持滚动定位。新提交要求非空蒙版。
  原始关联蒙版的灰度交集保持；主动编辑后的标记为二值。单边超过 4096 px 时使用
  工作台选区/关联蒙版，不在弹窗创建超大的交互画布。已提交 run 可直接恢复。

结果不再自动加入项目，先提供原图、结果和滑动对比，明确“应用为新图层”后完成操作关联。
可返回参数重新调整；过期预览拒绝应用，关联失败重试不重复添加图层或提交 AI。
当前线上老照片修复仍处于准备中，本轮只修改编辑器，不启用后台模型、不发布新版本。

### AI 结果尺寸与画布视野

尺寸变化的 AI 结果按源图层位置、变换及所属组加入，画布自动扩展以容纳完整结果；
结果越过左/上边界时移动画布原点，同步平移根图层与参考线，保持内容相对位置。
不自动缩小已有画布；同尺寸 AI 编辑保留原有裁剪范围。扩展超过图像资源上限时拒绝应用。
新增图层与画布扩展共用一次历史记录，撤销/重做同步恢复。

视野在画布宽高发生变化时自动适配，覆盖 AI、普通尺寸编辑和历史恢复；
仅调整面板或窗口大小时仍保持当前缩放与视野中心。缩放下限由 5% 调整为 1%，
避免大尺寸画布被旧下限阻挡而显示不全。
